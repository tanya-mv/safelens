# SafeLens — PPE Compliance Detector

Detects whether people in images are wearing required Personal Protective Equipment (PPE) — helmets, safety vests, gloves, and goggles — and flags violations.

## Tech Stack
- YOLOv8 (Ultralytics) — object detection
- FastAPI — backend REST API
- Next.js — frontend UI

## Status
🔨 In progress

## Planned Features
- Upload an image and get real-time PPE detection
- Bounding boxes drawn on violations
- Compliance report (who is/isn't wearing what)
- Live demo link

## Timeline
Built over 2–3 weeks as a placement portfolio project.
